# enquete — アンケート読み込み支援アプリ

紙のアンケート（PDF スキャン）の集計・電子化を支援する PySide6 製デスクトップアプリです。
サムネイル一覧・PDF 表示・入力フォームの 3 ペイン構成で、チェックボックスや丸囲み選択の
自動判定、自由記述欄の OCR、そして**結果を記入済み PDF 自身へ埋め込み保存**するところまでを
一気通貫で行います（サイドカー JSON は作らず、PDF 1 ファイルで自己完結します）。

## 主な機能

- **3 ペイン UI**: サムネイル / PDF プレビュー / 校正フォーム
- **原紙からフォーム作成（電子化フローに統合）**: 「電子化」で**クリーンな原紙 PDF を指定**すると、そこから設問・選択肢フォームを生成（テキスト層あり＝ベクタ抽出／スキャン＝OCR）。原紙を表示した編集モードで構造の確認・修正と自由記述の範囲指定を行い、確定すると読み取りに進みます。原紙に既存の埋め込み定義があればフォーム定義として再利用。「その他（　）」のような空欄括弧は自由入力欄として生成
- **PDF 自己完結（埋め込み）**: フォーム定義・全ページの校正結果／確認フラグ・差分基準（原紙）画像を、**記入済み PDF 自身へ添付として埋め込み**ます。サイドカー JSON は作らないので、その PDF を開けば作業を再開・検証できます（保存はロスレスなフル書き出しでファイルは肥大しません）
- **原紙＝フォーム生成元 兼 差分基準**: 指定した原紙 PDF は (1) フォーム定義の生成元、(2) 差分判定の基準、を兼ねます。原紙画像も記入済み PDF へ埋め込むので、以後の再電子化も PDF 単体で完結します
- **スキャン位置補正**: 電子化時、各ページを原紙に合わせて**自動整列**（Hough で水平化＋位相相関で平行移動）。スキャンの傾き・位置ずれを吸収して読み取り精度を上げます。原紙が電子データ出力 PDF のときは「原紙は電子PDF」チェックで水平化を省略
- **選択式の自動判定**: チェックボックス（□）・番号丸囲み（①②…）・丸文字選択をインク密度／リング解析で検出。**読み取りは「電子化」を押したときにまとめて実行**（開いた直後・ページ送りでは検出しません）
- **自由記述の OCR**: 領域を切り出して OCR（macOS=Apple Vision、Windows/Linux=Chrome screen-ai、Windows 標準 OCR にも対応）
- **作業モード（自動認識／校正）**: 電子化済み（埋め込みあり）の PDF は**校正モード**で開き、「電子化」「検出設定」「範囲編集」を不活性化して校正作業に集中できます。**確認済みページを編集すると確認が自動で外れ**、再度確認するか `Esc` で確認時点へ戻せます。**✓ 確認済み**にすると次の未確認ページへ自動で進みます
- **ダブルクリックで修正**: PDF 上のチェック□、またはその**選択肢テキスト**をダブルクリックでトグル（単一選択は排他）。PDF 表示と校正フォームは**スクロール連動**
- **全面オートセーブ**: 校正結果は編集の都度、記入済み PDF へ自動で埋め込み保存（明示保存は不要）
- **提出用に書き出す**: **全ページを確認済みにすると**「提出用に書き出す」が有効になり、PDF と同名・同ディレクトリへ集計用サイドカー JSON を書き出せます（PDF をそのまま返送しても、こちら側で書き出してもよい）
- **検出調整**: 検出設定で閾値・判定範囲（`box_expand`）などを調整、「適用（再電子化）」で全ページを再読み取り。ROI オーバーレイ（検出枠＋「選択済み」マーク）は判定範囲に連動して表示
- **手分け校正（分割 / マージ）**: 電子化済みの記入済み PDF を分割すると、各パートも結果・原紙画像を埋め込んだ**自己完結 PDF**になります → 各担当が**ファイル名を変えずに**校正して PDF（または提出 JSON）を返送 → マージで再結合
- **ドラッグ＆ドロップ**: サムネイル領域へ PDF を投入してページ挿入・別名保存

## ダウンロード（ビルド済みバイナリ）

macOS / Windows 向けのスタンドアロン版を配布します。

- **リリース**: [Releases](https://github.com/mashi727/enquete/releases) から取得（`v*` タグごとに自動添付）。
  - **Windows**: `enquete-windows.exe`（単一ファイル。ダウンロードしてダブルクリックで起動）
  - **macOS**: `enquete-macos.zip`（展開して `enquete.app` を起動）
- **最新ビルド**: GitHub の *Actions* → *Build binaries* の成果物（Artifacts）からも取得可能。

> ⚠️ バイナリは**コード署名・公証なし**です。
> - macOS: 初回は Finder で右クリック →「開く」、または `xattr -dr com.apple.quarantine enquete.app`
> - Windows: SmartScreen の「詳細情報」→「実行」（単一 exe は初回起動の自己展開でやや時間がかかります）
>
> ビルド方法・同梱方針は [`docs/build.md`](docs/build.md) を参照してください。

## 動作環境

- Python **3.12 以上**
- 依存: PySide6（LGPL）, pypdfium2（BSD）, pikepdf（QPDF/MPL-2.0・PDFへの埋め込み）, opencv-python-headless, numpy
- OCR バックエンド（任意・OS により選択）
  - macOS: `ocrmac`（Apple Vision）
  - Windows / Linux: `locro`（Chrome screen-ai）— `screenai` extra
  - Windows: `winsdk`（Windows.Media.Ocr）— `winocr` extra

## セットアップ

[uv](https://docs.astral.sh/uv/) を推奨します。

```bash
uv sync                      # 基本依存のみ
uv sync --extra screenai     # Chrome screen-ai OCR を併用する場合（Windows/Linux）
uv sync --extra winocr       # Windows 標準 OCR を併用する場合（Windows）
```

pip の場合:

```bash
pip install -e .
```

> **screen-ai について**: `locro` は PyPI 未公開のソース配布で、エンジン本体／モデルは
> 非再配布です。導入後に `locro download` で手元の Chrome からコピーする必要があります。
> 配布バイナリ（exe / .app）では `locro` を同梱しており、メニューの
> **ツール → OCRエンジン → 「screen-ai OCR を有効化…」** から一度だけ取得すれば
> 高精度な screen-ai OCR を利用できます。詳細は
> [`docs/ocr_windows.md`](docs/ocr_windows.md) を参照してください。

## 実行

```bash
uv run python -m enquete
```

## 使い方（標準フロー）

記入済みアンケートをスキャンした PDF（1 ページ＝1 回答）を読み込みます。
クリーンな原紙は**別の PDF ファイル**として用意します。
下段アクションバーが作業順に並んでいます。

1. **開く** — 記入済みアンケート PDF を開く（サムネイル領域への D&D も可）。
   埋め込みデータがあれば結果を復元して**校正モード**で開きます。無ければ次の「電子化」で原紙を指定します。
   生スキャン PDF を最初に開いたときは、配布時点の原本を `<名前>.bak.pdf` へ自動退避します
   （以後の埋め込み保存ではこの原本に常に戻れます）。
2. **電子化（原紙の指定＋読み取り）** — 「電子化」を押すと：
   - **まだ原紙が無いとき**は原紙 PDF（1 ページ）を選択 → 原紙を表示した**編集モード**に入り、設問・選択肢の
     確認/修正（「設問・選択肢を編集…」）や自由記述の**範囲指定**を行えます。原紙が電子データ出力なら
     「**原紙は電子PDF**」を ON（位置補正で原紙の水平化を省略）。**「✓ この原紙で電子化」**で確定 →
     全ページを原紙へ**位置補正** → **全ページのチェックを一括判定・自由記述を OCR**。`Esc` で編集を取消。
   - **すでに原紙が登録済みのとき**は、原紙を選び直さず**そのまま全ページを再電子化**します（＝検出設定の
     「適用（再電子化）」と同じ挙動）。
   - 原紙に既存の埋め込み定義があれば、それをフォーム定義として再利用します。
   - 登録済みの原紙の状態（読込済み／未指定）は**ステータスバー**に常時表示されます。
3. **校正** — **◀ / ▶** でページを送りながら結果を確認・修正。PDF 上のチェック□、またはその
   **選択肢テキスト**をダブルクリックでトグル（単一選択は排他）。自由記述は右ペインで直接修正。
   PDF と校正フォームは**連動スクロール**します。**✓ 確認済みにする**でページに確認印（サムネイルに表示）が付き、
   次の未確認ページへ自動で進みます。
4. **検出設定**（必要時）— 閾値・判定範囲（`box_expand`）などを調整。**「適用（再電子化）」**で
   原紙を選び直さずに全ページを再読み取りします。各項目はマウスホバーで説明が出ます。
5. **提出用に書き出す** — **全ページを確認済み**にするとボタンが有効になり、集計用サイドカー JSON を
   PDF と同名・同ディレクトリへ書き出せます（PDF をそのまま返送する運用でも可）。

> - **作業モード**：「モード: 自動認識／校正」を切替。**校正モード**では「電子化」「検出設定」「範囲編集」が
>   不活性になり、校正に必要な操作だけになります（担当者へ校正のみ依頼する場合に便利）。確認済みページを
>   編集すると確認が自動で外れ、再度「✓ 確認済みにする」または `Esc` で確認時点へ戻せます。
> - 「**モデル: …**」ドロップダウンで OCR エンジン（自動 / Apple Vision /
>   Chrome screen-ai / Windows 標準）を切り替えられます（ツール → OCRエンジンと同期）。
> - 拡大縮小は **Ctrl ＋ マウスホイール**（Windows）／ピンチ（macOS トラックパッド）。

校正結果は編集の都度、**記入済み PDF 自身へ埋め込み**で**自動保存**されます（明示的な保存操作は不要）。
保存はロスレスなフル書き出しでその場上書きするため、ファイルは肥大しません。配布時点の原本は、
生スキャン PDF を最初に開いたときに `<名前>.bak.pdf` へ退避してあるので常に復元できます
（埋め込み済み PDF を開いたときは `.bak` を作りません）。

### 手分けして校正する（分割・マージ）

1. 主催側で **電子化**まで済ませる（記入済み PDF に読み取り結果が埋め込まれます）。
2. **ツール → アンケートを分割…**で N 分割。各パートは「フォーム・担当ページの結果・原紙画像」を
   埋め込んだ**自己完結 PDF**になります。
3. 各担当へ配布。担当は**校正モード**で開き、**ファイル名を変えずに**校正して、**PDF をそのまま**
   （または「提出用に書き出す」で出した **JSON を**）返送します。
4. 主催側で返ってきた PDF / JSON を集め、**ツール → アンケートをマージ…**で再結合します
   （統合結果も埋め込み済みの 1 つの PDF として書き出されます）。
